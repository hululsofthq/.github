# Hululsoft

We build websites, mobile apps and business systems, in Arabic, French and English.

Some of our work is open source:

- [Nezzel](https://github.com/hululsofthq/nezzel): save videos, audio and photos from public links on Android
- [quran-mr](https://github.com/hululsofthq/quran-mr): the Quran in the Warsh reading, for the web
- [LibreTier](https://github.com/hululsofthq/LibreTier): free tiers of developer tools, in one place
